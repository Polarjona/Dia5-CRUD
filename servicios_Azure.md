# Identificación y documentación de 5 servicios cognitivos de Azure

## 1. API de Face (Face API)

### Descripción
Azure Face API es un servicio de inteligencia artificial que permite detectar, analizar y comparar rostros en imágenes y vídeos.

### Funcionalidades principales
- Detección de rostros.
- Comparación facial.
- Verificación de identidad.
- Agrupación de rostros similares.

### Casos de uso
- Control de acceso mediante reconocimiento facial.
- Registro de asistencia de empleados.
- Verificación de identidad en entidades bancarias.
- Sistemas de videovigilancia y seguridad.

---

## 2. Computer Vision

### Descripción
Computer Vision permite analizar imágenes para extraer información mediante algoritmos de inteligencia artificial.

### Funcionalidades principales
- Reconocimiento de objetos.
- Detección de texto (OCR).
- Análisis de contenido visual.
- Generación automática de descripciones de imágenes.

### Casos de uso
- Digitalización de documentos físicos.
- Sistemas de control de inventario mediante fotografías.
- Aplicaciones de accesibilidad para personas con discapacidad visual.
- Moderación automática de contenido visual.

---

## 3. Azure AI Document Intelligence

### Descripción
Servicio diseñado para extraer y estructurar información contenida en documentos, formularios y facturas.

### Funcionalidades principales
- Extracción de datos de formularios.
- Procesamiento de facturas y recibos.
- Análisis de contratos.
- Conversión de documentos en datos estructurados.

### Casos de uso
- Automatización de procesos administrativos.
- Gestión documental empresarial.
- Procesamiento de solicitudes y formularios.
- Digitalización de archivos físicos.

---

## 4. Translator

### Descripción
Azure Translator proporciona traducción automática en múltiples idiomas utilizando inteligencia artificial.

### Funcionalidades principales
- Traducción de texto.
- Detección automática del idioma.
- Traducción en tiempo real.
- Traducción de documentos completos.

### Casos de uso
- Sitios web multilingües.
- Atención al cliente internacional.
- Traducción de documentación corporativa.
- Aplicaciones de comunicación global.

---

## 5. Speech Services

### Descripción
Speech Services permite convertir texto en voz y voz en texto mediante tecnologías de procesamiento del lenguaje natural.

### Funcionalidades principales
- Speech-to-Text (voz a texto).
- Text-to-Speech (texto a voz).
- Reconocimiento de comandos de voz.
- Traducción de voz en tiempo real.

### Casos de uso
- Asistentes virtuales y chatbots.
- Transcripción automática de reuniones.
- Centros de atención telefónica.
- Sistemas domóticos controlados por voz.
